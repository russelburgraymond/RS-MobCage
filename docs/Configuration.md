# Configuration

RS-MobCages currently requires little to no configuration.

The plugin is designed to work immediately after installation without requiring players or server administrators to configure commands, permissions, or complex settings.

---

## Default Configuration

After RS-MobCages is installed and the server is started, the plugin will create any required plugin files and use its default settings.

For most servers, no additional configuration is required.

---

## Configuration File

If RS-MobCages includes a configuration file, it can be found in:

    plugins/RS-MobCages/

Any available configuration options will be listed and explained in this documentation as they are added to the plugin.

---

## Current Configuration Options

RS-MobCages does not currently require any configuration changes for normal operation.

The plugin is designed to work with its default behavior after installation.

---

## Future Configuration Options

Additional configuration options may be added in future versions as the plugin expands.

If new options are introduced, this page will be updated to include:

- The configuration option name.
- Its default value.
- What the option controls.
- Any valid values or limitations.
