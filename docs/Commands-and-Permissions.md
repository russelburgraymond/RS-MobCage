# Commands and Permissions

RS-MobCages does not currently require any commands or permissions for normal use.

Players interact directly with Mob Cages to capture and release supported mobs.

---

## Commands

RS-MobCages currently does not provide any player or administrator commands.

All normal interaction is performed directly in-game using Mob Cages.

---

## Permissions

RS-MobCages currently does not require any permissions.

If the plugin is installed and enabled, players can use supported Mob Cages normally.

---

## Future Commands and Permissions

Commands and permissions may be added in a future version if they become necessary.

Any new commands or permissions will be documented here.
